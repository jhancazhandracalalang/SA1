# Item 1: Probability of a Defective Product

## Objective

Calculate the probability that a randomly selected product is defective when three factories produce the product in different proportions and have different defective rates.

## Method

The overall probability of a defective product is calculated using:

\[
P(D)=x_1y_1+x_2y_2+x_3y_3
\]

where:

- \(x_1,x_2,x_3\) represent the production proportions of the three factories.
- \(y_1,y_2,y_3\) represent the defective rates of the three factories.
- \(P(D)\) represents the probability that a randomly selected product is defective.

## Input Validation

The program checks the following conditions:

- Each production proportion must be between 0.10 and 0.40.
- The sum of the production proportions must equal 1.
- Each defective rate must be between 0.01 and 0.05.
- The sum of the defective rates must equal 0.12.

If the entered values do not satisfy these conditions, the program asks the user to enter the values again.

## How to Run

1. Open `Item1_Factory_Probability.R` in RStudio.
2. Open the Console.
3. Run the following command:

```r
source("Item1_Factory_Probability.R")
```

4. Enter the production proportions and defective rates when prompted.

## Test Data

| Factory | Production Proportion | Defective Rate |
|---|---:|---:|
| Factory 1 | 0.40 | 0.05 |
| Factory 2 | 0.30 | 0.04 |
| Factory 3 | 0.30 | 0.03 |
| **Total** | **1.00** | **0.12** |

## Expected Result

Using the test data:

\[
\begin{aligned}
P(D)&=(0.40)(0.05)+(0.30)(0.04)\\
&\quad +(0.30)(0.03)\\
&=0.020+0.012+0.009\\
&=0.041
\end{aligned}
\]

The expected probability of a defective product is **0.041, or 4.1%**.

## Interpretation

The probability that a randomly selected product is defective is calculated by multiplying each factory's production proportion by its corresponding defective rate and adding the three contributions. Based on the test data, the overall defective probability is 4.1%.

# Item 2: Univariate and Bivariate Discrete Probability Distributions

## Objective

Develop an interactive front end that allows users to enter the values of discrete random variables and their corresponding probabilities and obtain the required probability distributions and statistical results.

## Features

The Shiny application provides the following functions:

- Accepts user inputs for discrete random variable values and probabilities.
- Checks that probabilities are between 0 and 1.
- Checks that probabilities sum to 1.
- Calculates the mean and variance of a univariate discrete random variable.
- Displays the probability distribution table.
- Plots the probability mass function (PDF) and cumulative distribution function (CDF).
- Accepts the joint probability matrix of a bivariate discrete random variable.
- Calculates the marginal distributions of \(X\) and \(Y\).
- Calculates the conditional distributions of \(X\) given \(Y\) and \(Y\) given \(X\).
- Calculates the mean and variance of the marginal and conditional distributions.
- Displays tables and PDF/CDF plots for the marginal distributions.

## How to Run

1. Open `Item2_Discrete_Distributions.R` in RStudio.
2. Run the complete script using the following command in the Console:

```r
source("Item2_Discrete_Distributions.R")
```

3. The Shiny application will open in the RStudio Viewer or a web browser.
4. Select either the **Univariate** or **Bivariate** tab.
5. Enter the required values and probabilities.
6. Click the corresponding calculation button to display the results.

## A. Univariate Discrete Random Variable

### Test Data

| Value of X | Probability |
|---:|---:|
| 0 | 0.10 |
| 1 | 0.20 |
| 2 | 0.40 |
| 3 | 0.30 |
| **Total** | **1.00** |

### Formulas

The mean is calculated using:

\[
E(X)=\sum xP(X=x)
\]

The variance is calculated using:

\[
\operatorname{Var}(X)=
\sum (x-E(X))^2P(X=x)
\]

### Expected Results

The expected mean is:

\[
E(X)=0(0.10)+1(0.20)+2(0.40)+3(0.30)=1.90
\]

The expected variance is:

\[
\operatorname{Var}(X)=0.89
\]

| Statistic | Expected Result |
|---|---:|
| Mean | 1.90 |
| Variance | 0.89 |

### Interpretation

The mean of 1.90 represents the probability-weighted average of the possible values of the random variable. The variance of 0.89 measures how much the values vary around the mean, taking their probabilities into account.

The PDF displays the probability associated with each value, while the CDF displays the cumulative probability up to each value.

## B. Bivariate Discrete Random Variable

### Test Data

Values of \(X\): 0 and 1

Values of \(Y\): 0 and 1

Joint probability matrix:

Each row corresponds to a value of \(Y\), and each column corresponds to a value of \(X\).

### Marginal Distributions

The marginal distribution of \(X\) is obtained by summing the joint probabilities across each column.

The marginal distribution of \(Y\) is obtained by summing the joint probabilities across each row.

| Value of X | Marginal Probability |
|---:|---:|

### Expected Marginal Statistics

| Distribution | Mean | Variance |
|---|---:|---:|

| Y | 0.70 | 0.21 |

### Conditional Distributions

The conditional probability of \(X\) given \(Y=y\) is:

\[
P(X=x\mid Y=y)=
\frac{P(X=x,Y=y)}{P(Y=y)}
\]

The conditional probability of \(Y\) given \(X=x\) is:

\[
P(Y=y\mid X=x)=
\frac{P(X=x,Y=y)}{P(X=x)}
\]

The application calculates these conditional probabilities for every possible conditioning value. It also calculates the corresponding conditional means and variances.

### Expected Conditional Statistics

| Conditional Distribution | Mean | Variance |
|---|---:|---:|
| \(X\mid Y=0\) | 0.6667 | 0.2222 |
| \(X\mid Y=1\) | 0.5714 | 0.2449 |
| \(Y\mid X=0\) | 0.7500 | 0.1875 |
| \(Y\mid X=1\) | 0.6667 | 0.2222 |

### Interpretation

Marginal distributions describe the probabilities of one random variable without conditioning on the other variable. Conditional distributions describe the probabilities of one variable when the value of the other variable is known.

The mean and variance summarize the center and spread of each marginal and conditional distribution. The PDF and CDF plots of the marginal distributions provide additional visual representations of the probabilities.

# Item 3: Search Engine Simulation

## Objective

Conduct a simulation experiment involving 10,000 searches to model the number of searches required for a search engine to find a key phrase for the first time.

The program allows the user to enter the probability \(p\) that a site contains the key phrase.

## Method

The number of searches until the first success follows a geometric distribution.

The program uses R's `rgeom()` function to generate the number of failures before the first success. One is added to each simulated value so that \(X\) represents the total number of searches, including the successful search.

The simulation calculates:

- The simulated probability mass function (PDF).
- The simulated cumulative distribution function (CDF).
- The simulated mean and variance.
- The conditional distribution after three unsuccessful searches.
- The conditional mean and variance.
- Estimates for the two required memoryless property comparisons.

## How to Run

1. Create the `outputs/` folder in the project directory if it does not exist.
2. Open `Item3_Search_Simulation.R` in RStudio.
3. Run the complete script using:

```r
source("Item3_Search_Simulation.R")
```

4. Enter `0.60` as the probability of success.
5. Press Enter when asked for the number of simulations to use the default of 10,000.
6. Review the results in the Console and the plots displayed by RStudio.

## Test Data

| Parameter | Value |
|---|---:|
| Number of simulations | 10,000 |
| Probability of success, \(p\) | 0.60 |

## Formulas

The theoretical mean of a geometric random variable is:

\[
E(X)=\frac{1}{p}
\]

The theoretical variance is:

\[
\operatorname{Var}(X)=\frac{1-p}{p^2}
\]

For \(p=0.60\):

\[
E(X)=\frac{1}{0.60}\approx1.6667
\]

\[
\operatorname{Var}(X)=
\frac{1-0.60}{(0.60)^2}
\approx1.1111
\]

## Expected Theoretical Results

| Statistic | Theoretical Value |
|---|---:|
| Mean | 1.6667 |
| Variance | 1.1111 |
| \(P(X=1)\) | 0.6000 |
| \(P(X=2)\) | 0.2400 |

The simulated values may differ slightly from the theoretical values because of random sampling variation.

## Conditional Distribution After Three Unsuccessful Searches

The condition \(X>3\) means that the first three searches were unsuccessful.

The program examines the number of additional searches, calculated as \(X-3\), until the first success.

The geometric distribution has the memoryless property:

\[
P(X-3=k\mid X>3)=P(X=k)
\]

for \(k=1,2,\ldots\).

Therefore, the conditional mean and variance of the number of additional searches should be approximately equal to the original theoretical mean and variance.

| Statistic | Theoretical Value |
|---|---:|
| Conditional mean of additional searches | 1.6667 |
| Conditional variance of additional searches | 1.1111 |

The conditional sample contains only simulations in which more than three searches were required, so its estimates may differ from those of the complete sample.

## Memoryless Property Tests

The program estimates the following probabilities:

### Comparison A

\[
P(X=4\mid X>3)=P(X=1)
\]

The theoretical value of both probabilities is:

\[
P(X=1)=p=0.60
\]

### Comparison B

\[
P(X=5\mid X>3)=P(X=2)
\]

The theoretical value of both probabilities is:

\[
P(X=2)=(1-p)p=0.24
\]

### Interpretation

The estimated conditional probabilities should be reasonably close to their corresponding original probabilities. This supports the memoryless property of the geometric distribution, which states that the distribution of the number of additional searches does not depend on the number of previous unsuccessful searches.

Small differences between the estimated and theoretical probabilities are expected because the simulation uses a finite number of observations.
